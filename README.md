# ファイル一発開くくん

Windows PowerShell 5.1で動作する、ファイル名の部分一致検索とファイル起動用のCUIスクリプトである。

## 設定と実行

`DirectFileOpenPS.ps1`の先頭にある`$SearchDirectory`を検索対象ディレクトリのパスに変更する。既定値はスクリプトの保存先である。

```powershell
$SearchDirectory = 'C:\pleiades'
$ExcludedDirectories = @(
    'C:\pleiades\cache'
    'C:\pleiades\2026-06\eclipse\plugins'
)
```

`$SearchDirectory`の直下にある`$ExcludedDirectories`へ、検索から除外するフォルダを絶対パスで複数指定できる。ドライブ付き絶対パス（`C:\folder`）とUNCパス（`\\server\share\folder`）に対応する。相対パス（`cache`、`C:cache`、`\cache`など）は設定エラーになる。検索結果を取得した後、指定したフォルダ配下のファイルをリストから削除する。除外が不要な場合は`@()`とする。

除外パスは大文字・小文字を区別せず、フォルダ単位で比較する。`cache`を除外しても`cache-backup`は除外しない。ワイルドカードは使用しない。存在しない除外パスは検索結果に影響しない。検索対象自身やその親フォルダを除外した場合は検索結果が0件になる。

除外フォルダ内も検索時には走査するため、除外指定によって検索時間は短縮されない。除外フォルダ内の読み取りエラーも警告の対象となる。

Windows PowerShellでスクリプトの保存先へ移動し、次のコマンドを実行する。

```powershell
.\DirectFileOpenPS.ps1
```

実行ポリシーにより起動が拒否される場合は、次のコマンドで起動プロセスだけに適用する実行ポリシーを指定できる。保存済みの実行ポリシーは変更しない。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\DirectFileOpenPS.ps1
```

日本語を含むため、スクリプトを編集・保存する際はUTF-8 BOM付きの文字コードを維持する必要がある。

## 操作

1. 表示された検索対象ディレクトリを確認し、ファイル名の一部を入力してEnterを押す。
2. 番号付きのフルパス一覧から対象を選ぶ。
3. `1`などの番号を入力すると、そのファイルを既定のプログラムで開く。`1d`と入力すると、保存先フォルダをエクスプローラーで開く。
4. 起動後も同じ一覧の番号を続けて入力できる。`0`を入力するとファイル名の検索へ戻る。
5. 終了する際はコンソールのウィンドウを閉じる。終了コマンドは設けていない。

検索はサブディレクトリと隠しファイルを含み、ファイル名の大文字・小文字と半角・全角を区別しない。例として`ABC`は`ａｂｃ`に、`ｶﾀｶﾅ`は`カタカナ`に一致する。`*`、`?`、`[`などは通常の文字として扱う。検索文字列の前後の空白も検索対象の一部であり、空入力や空白だけの入力は受け付けない。

検索結果はフルパス順で表示する。一致するファイルがない場合は再び検索入力を待つ。読み取れない項目がある場合は警告を表示し、読み取れた範囲の結果を表示する。不正な番号やファイル起動の失敗後も入力を継続できる。

## 検証

追加モジュールを必要としない自動テストを用意している。リポジトリのルートから次のコマンドを実行する。

```powershell
powershell.exe -NoProfile -File .\tests\DirectFileOpenPS.Tests.ps1
```

テストも実行ポリシーにより拒否される場合は、上記と同様に`-ExecutionPolicy Bypass`を指定する。

テストでは一時ファイルを使って検索と入力遷移を検証し、ファイル起動とエクスプローラー起動は代替関数で引数を確認する。実際の関連付けによる起動は手動確認の対象である。
